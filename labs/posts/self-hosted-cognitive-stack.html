Run Your Own Mind Tools: Focus, Memory, and Automation You Control

Excalidraw is not heavy to host. The harder question is which open-source tools earn a permanent slot because they solve one friction point extremely well.

Short answer first: personally hosting Excalidraw is light. The static client-side app is enough for solo drawing. Real-time collaboration needs a small WebSocket room service, a reverse proxy, and HTTPS - still tiny by VPS standards. Think roughly a modest vCPU and under a gig of RAM for personal use, usually via Docker Compose.

Do not build a museum of canvases. Build a stack that protects attention, memory, and execution.

Selection rule

Nitish Chauhan's filter for open-source tools is intentionally narrow: not “is it popular,” but “does this solve one specific friction with applause from people who actually use it?” Prefer sharp small tools over bloated suites. Prefer local ownership when the data is cognitive, not decorative.

A practical personal stack

Executive function

  • Goblin Tools: decompose vague tasks into steps when initiation is the bottleneck.
  • Super Productivity / Vikunja: task surfaces that do not require a second PhD to start.
  • ActivityWatch: automatic local time truth instead of optimistic journaling.

Knowledge and recall

  • Logseq / Trilium / TiddlyWiki: different shapes of second brain - outliner, hierarchy, or single-file wiki.
  • Anki / Mnemosyne: spaced repetition when upskilling must stick.
  • Zotero: research capture that does not dissolve into browser tabs.
  • Memos / Silverbullet: fast capture without ceremony.

Automation and infra glue

  • n8n: self-hosted workflows when Zapier rent gets silly.
  • Vaultwarden: credentials you actually control.
  • Gitea + Coolify: lightweight code hosting and deploy control on a small VPS.
  • Uptime Kuma: so your personal stack does not silently die.

Underrated terminal gems

  • Espanso: text expansion as cognitive offload.
  • Lazygit / Zoxide / Broot / cheat.sh: navigation and recall speed for people who live in the shell.

Excalidraw's real role

Put Excalidraw (or tldraw / draw.io) in the stack as a thinking surface, not the whole operating system. Use it to externalize system maps, then park the durable decisions elsewhere - notes, Anki, experiments log, agent memory. Canvas without capture is entertainment. 

Friction → one sharp tool
Map → Excalidraw
Memory → notes + spaced repetition
Automation → n8n
Agent door → Hermes / WebUI
Files → Nextcloud

NitishLabs rule of thumb

Host what compounds your cognition and ownership. Skip what only looks powerful in a screenshot. A VPS is not a personality. It is a workshop. Stock it with tools that remove one real failure mode at a time.

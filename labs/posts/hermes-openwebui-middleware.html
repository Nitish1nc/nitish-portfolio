The Chat Window Isn't the Brain: Face vs Engine in AI Tools

Open WebUI is more of an interface. Hermes is more on the middleware side. End of day, people tool out what they like - architecture still decides who wins.

Tool debates get noisy because people compare layers as if they were peers. Nitish Chauhan's working distinction is cleaner: Open WebUI is primarily a face / session interface. Hermes is the agentic loop, memory, and tool-execution middleware. You can run either alone. You can also stack them.

Prompt lands in the UI. UI posts to Hermes. Hermes decides whether to use tools, executes, and streams results back. Same agent, better surface area.

Where it sits on a real VPS

If you already own a domain, a VPS, Nextcloud, and a Hermes agent on Telegram, Open WebUI does not replace the whole world. It becomes another door into the same brain - usually on a subdomain, behind HTTPS, next to your other services.

  • Hermes: persistent agent, tools, memory, multi-channel gateway.
  • Open WebUI: richer history, uploads, structured sessions, desktop-grade chat.
  • Telegram: fast, low-friction mobile pings. Keep it if it earns its keep.
  • Nextcloud: files and sync. Different job. Same real estate.
You do not need to delete Telegram to get a better interface. Channels can coexist.

Mobile reality check

On Android, a native client like Conduit often feels better than a browser wrapper: WebSocket streaming, cleaner auth storage, share-sheet into prompts, voice call mode. The PWA remains a solid fallback and usually tracks new Open WebUI features faster. Voice mode does not magically burn extra LLM tokens by itself - speech becomes text first - but external STT/TTS providers can add separate costs, and chat UIs that spawn follow-up suggestion calls can inflate session usage.

The NitishLabs take

People will tool out what they like. Fine. Just do not confuse the face with the nervous system. Build the middleware once. Attach interfaces based on context: Telegram for quick hits, WebUI for deep work, native mobile when the browser starts fighting you. That is systems thinking applied to agent UX - not another loyalty test for a logo.

Running Self-hosted middleware

Hermes Agent Stack

Open WebUI is a face. Hermes is the brain. Pick the interface you like - keep the agent loop, tools, and memory on the VPS.

What

Hermes runs as systemd on Nitish Chauhan's VPS with Telegram webhook access (@OGHermes_1bot) and a WebUI at chat.nitishchauhan.com. OpenAI-compatible API means alternate faces (Open WebUI, mobile PWA, etc.) can plug in without replacing middleware. Nextcloud stays on cloud. for files; portfolio stays on the main domain.

Why

Phone-first control without pretending Telegram is a full IDE. Lab notes sketch Historian-style day narratives and question-preserving compression - those are workers that need a durable agent runtime, not another disposable chatbot tab. End of day, people tool-out what they like; the stack should survive that.

Status

Live. Webhook mode preferred over long polling. WebUI on loopback behind nginx TLS. This is production personal infra for NitishLabs - not a slideware agent.

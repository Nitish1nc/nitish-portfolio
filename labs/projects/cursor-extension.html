Prototype Phase 1 MVP

Memory Capture

A perfect screwdriver. Highlight → Export to Memory. No prompts. No cloud. Files land in Memory/Inbox/YYYY/MM/DD/.

What

Cursor-optimized Manifest V3 extension: page / selection / link capture, Turndown Markdown with a fixed metadata header, silent chrome.downloads, duplicate hashing, and a Friction Counter CSV for moments that still hurt. ChatGPT & Claude DOM heuristics with a generic fallback. Strict Phase 1 exclusions: OCR, AI summaries, cloud sync, folder pickers.

Why

Organize later. At discovery time, every extra decision is friction. The implementation guide's core rule: never ask the user a question during capture. Inbox-first keeps the ADHD brain moving; sorting is tomorrow's problem - which is a compliment, not a bug.

Status

Source lives in NitishLabs active-projects/memory-capture-extension, built to the Phase 1 guide. Upstream productization path is Vault (queue sidebar + multi-format export). This MVP proves silent local capture first.
